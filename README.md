# 📖 言未盡處 (Beyond Words) | Sunny Lee 心靈小說書房

> **「那些未曾說出口的話，在這裡都被溫柔聽見。」**

專為 **紙本書深度閱讀體驗** 與 **溫馨教練陪伴** 打造的多書作品集網站，部署於 GitHub Pages。

---

## ✨ 網站亮點 (Features)

- **📚 多作品書架架構 (Multi-Book Architecture)**：完整收錄長篇心理巨作《那些沒有說出的話》（已收錄 16 回，約 9.6 萬字），並預留後續作品（如《聽見影子的心跳》）的擴充插槽。
- **📜 極致紙本書閱讀體驗 (Paper Book Experience)**：
  - 嚴選 **思源宋體 (Noto Serif TC)** 襯線字體，排版依循傳統出版書籍黃金行距與首行兩字縮排。
  - **三種精緻閱讀紙張底色**：
    1. 📜 **文庫暖紙** (Warm Parchment · 預設)：溫潤柔和、護眼舒適。
    2. 🌙 **夜讀深黛** (Night Ink)：深色護眼、靜謐沉浸。
    3. ☀️ **晨光柔白** (Clean Light)：清爽簡潔。
  - **【易新省思札記】便籤卡片**：每一節的情感自白以羊皮紙/手記卡片形式獨立呈現，引導讀者沉澱與覺察。
- **📑 靈動閱讀輔助**：
  - 原生 `<dialog>` 側邊抽屜式全書目錄。
  - 頂部微縮閱讀進度條。
  - `A-` / `A+` 即時字級縮放。
  - 鍵盤快捷鍵翻頁（`←` 上一回、`→` 下一回）。
  - 自動記憶各本書的最後閱讀進度（LocalStorage）。
- **📱 全響應式美學 (Responsive)**：完美相容手機、平板與桌上型電腦。

---

## 🛠️ 技術架構 (Tech Stack)

- **前端**：純原生現代 HTML5、現代 CSS (Design Tokens, `light-dark()`, 玻璃擬態, CSS Grid/Flexbox)、原生 JavaScript (ES6+)。
- **無依賴、無編譯負擔**：極致輕量，加載神速，開箱即用，對 GitHub Pages 零門檻。
- **字型**：Google Fonts `Noto Serif TC` & `Outfit`。
